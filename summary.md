# Cybersecurity Analyzer Agent Summary

This repository contains the **Cybersecurity Analyzer Agent**, a web-based tool designed to identify security vulnerabilities in Python code.

## Key Capabilities

*   **AI-Driven Analysis**: Utilizes OpenAI's agents to understand code logic and potential security flaws.
*   **Static Code Analysis**: Incorporates Semgrep via the Model Context Protocol (MCP) for rigorous vulnerability scanning.
*   **Interactive Chat**: Features a chat interface for users to discuss findings and remediation strategies with the AI.
*   **Cloud-Native**: Architected for deployment on serverless container platforms like Azure Container Apps and Google Cloud Run.

## Purpose

The tool serves as a practical example of building and deploying agentic AI applications with modern cloud infrastructure, bridging the gap between static analysis and LLM-based reasoning.
